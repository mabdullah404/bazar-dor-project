## 🎯 প্রজেক্টের লক্ষ্য ও উদ্দেশ্য (Project Philosophy)
বাংলাদেশের নিত্যপণ্যের বাজারে প্রতিদিন কোনো না কোনো পণ্যের দাম পরিবর্তিত হয়। তথ্যের ঘাটতি ও বিভিন্ন বাজারের মূল্যের তারতম্যের কারণে ভোক্তাদের প্রায়ই বিভ্রান্ত হতে হয়। **বাজার দর** প্ল্যাটফর্মটির লক্ষ্য হলো:
- সাধারণ ভোক্তাদের স্বচ্ছ ও নির্ভরযোগ্য বাজার দরের তথ্য দেওয়া।
- কোন বাজারে একই পণ্য কত দামে মিলছে তার সরাসরি তুলনামূলক চিত্র তুলে ধরা।
- ইন্টারেক্টিভ ও নান্দনিক ইউজার ইন্টারফেসের মাধ্যমে সহজে যে কারো ব্যবহারের উপযোগী করা।

## 🌟 উল্লেখযোগ্য ও প্রধান বৈশিষ্ট্যসমূহ (Key Highlights & Features)

### ১. ⚡ রিয়েল-টাইম প্রাইস ট্র্যাকার মারকুই (Live Price Ticker Bar)
- ব্যানারের ঠিক নিচেই অনবরত চলমান একটি ফ্লুইড মারকুই স্ট্রিপ, যা বিভিন্ন ক্যাটাগরির পণ্যের আজকের দর, পরিমাপের একক এবং গতকালের তুলনায় দাম বৃদ্ধির (▲ লাল) বা হ্রাসের (▼ সবুজ) হার বাংলা সংখ্যায় দেখায়।
- ব্যবহারকারী চাইলে যেকোনো আইটেমে মাউস নিয়ে থামিয়ে (`pause on hover`) বিস্তারিত পড়তে পারেন।

### ২. 🗂️ মাল্টি-ক্যাটাগরি নেভিগেশন ও ডায়নামিক রাউটিং (`/category/[slug]`)
- চাল, ডাল, তেল, সবজি, মাছ, মাংস, মসলাসহ সকল নিত্যপণ্যের জন্য ক্যাটাগরি পিলস নেভিগেশন।
- ডেডিকেটেড ক্যাটাগরি পেজে সরাসরি ফিল্টারকৃত পণ্য প্রদর্শন এবং সক্রিয় ক্যাটাগরিতে ভিজ্যুয়াল গ্রিন হাইলাইট।

### ৩. 🔀 তাৎক্ষণিক প্রাইস সর্টিং ইঞ্জিন (Dynamic Sorting Dropdown)
- ব্যবহারকারী নিজের সুবিধামতো প্রডাক্ট কার্ডগুলো ৩টি অর্ডারে সাজাতে পারেন:
  - **স্বাভাবিক বা ডিফল্ট ক্রম**
  - **দাম: কম থেকে বেশি (Lowest First)**
  - **দাম: বেশি থেকে কম (Highest First)**
- ক্লায়েন্ট সাইডেই কোনো পেজ রিলোড ছাড়াই মসৃণ ট্রানজিশনে পণ্যের গ্রিড রি-অর্ডার হয়।

### ৪. 🛡️ সুরক্ষাবেষ্টিত প্রডাক্ট ডিটেইলস পোর্টাল (Protected Route: `/products/[id]`)
- যেকোনো পণ্যের মার্কেটভিত্তিক বিস্তারিত বিবরণ, গড় মূল্য, সর্বোচ্চ-সর্বনিম্ন বিশ্লেষণ দেখতে হলে ইউজারের লগইন বাধ্যতামূলক।
- লগআউট অবস্থায় প্রডাক্টে ক্লিক করলে সাইন-ইন পেজে রিডাইরেক্ট করে এবং সফল সাইন-ইনের পর স্বয়ংক্রিয়ভাবে কাঙ্ক্ষিত প্রডাক্ট পেজেই ফিরিয়ে নেয়।

### ৫. 🔐 সিকিউর সাইন-আপ ও ইন্টারেক্টিভ পাসওয়ার্ড কন্ট্রোল
- ব্যবহারকারী যাতে পাসওয়ার্ড টাইপ করার সময় ভুল না করেন, সেজন্য সাইন-আপ ও সাইন-ইন উভয় ফর্মে বাংলায় **"দেখুন / লুকান"** আই-টগল সুবিধা দেওয়া হয়েছে।
- সাইন-আপ সম্পন্ন হওয়ার সাথে সাথেই ব্যবহারকারী সরাসরি অথেনটিকেটেড হয়ে হোম পেজে প্রবেশ করতে পারেন।

### ৬. 👤 পার্সোনালাইজড ইউজার প্রোফাইল (`/profile/update`)
- লগইন করা ইউজারের জন্য নেভবারে কাস্টম এভাটার ড্রপডাউন মেনু।
- ব্যবহারকারী নিজের নাম পরিবর্তন করতে চাইলে ডেডিকেটেড প্রোফাইল আপডেট পেজ থেকে যেকোনো সময় নাম আপডেট করতে পারেন।

### ৭. 📱 ১০০% ডিভাইস-ফ্রেন্ডলি রেসপনসিভনেস (Mobile-First Layout)
- ৩২০ পিক্সেল স্মার্টফোন থেকে শুরু করে বড় ডেস্কটপ মনিটর পর্যন্ত প্রতিটি কম্পোনেন্ট স্বয়ংক্রিয়ভাবে চমৎকারভাবে মানিয়ে যায়।

## 💻 লোকাল মেশিনে ইনস্টলেশন ও রান করার নিয়ম (Getting Started)

### ১. ক্লোন ও ডিরেক্টরিতে প্রবেশ
```bash
git clone https://github.com/mabdullah404/bazar-dor-project.git
cd bazar-dor-project
```

### ২. প্যাকেজ ইন্সটল করুন
```bash
npm install
```

### ৩. এনভায়রনমেন্ট কনফিগারেশন (`.env` ফাইল)
প্রজেক্টের রুট ডিরেক্টরিতে একটি `.env` ফাইল তৈরি করে নিচের ভ্যারিয়েবলগুলো প্রদান করুন:
```env
BETTER_AUTH_SECRET="your_custom_secret_key"
BETTER_AUTH_URL="http://localhost:3000"
BETTER_AUTH_MONGO_URI="mongodb+srv://<username>:<password>@cluster.mongodb.net/bazar_dor_db"
```

### ৪. ডেভেলপমেন্ট সার্ভার চালু করুন
```bash
npm run dev
```
ব্রাউজারে [http://localhost:3000](http://localhost:3000) ওপেন করে প্রজেক্টটি ব্রাউজ করুন।
